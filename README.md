# 22408 复习计划（2028 考研：数学二 + 408 + 英语 + 政治）

一个纯静态的每日复习计划页 + 一个 Obsidian 笔记库 + 一份 Excel 计划表，三边共用同一套数据。双击 `22408每日计划.html` 就能用，不需要服务器、不需要联网、不需要装任何东西。

四科共用一个「阶段」框架，日期从初试 2027-12-25 倒排：

| 阶段 | 时间 | 周数 | 数学二 | 408 | 英语 | 政治 |
|---|---|---|---:|---|---|---|
| 第一阶段 | 2026-11-09 ~ 2027-03-14 | 18 | 一轮基础 | 一轮基础 | 单词打底 | 不启动 |
| 第二阶段 | 2027-03-15 ~ 2027-06-27 | 15 | 二轮基础 | 二轮基础 | 单词 + 阅读 | 不启动 |
| 第三阶段 | 2027-06-28 ~ 2027-09-26 | 13 | 强化 | 强化 | 阅读 + 题型 | 不启动 |
| 第四阶段 | 2027-09-27 ~ 2027-12-26 | 13 | 真题 | 真题 | 作文 + 真题 | 11 月启动：肖八 → 肖四 |

政治单独一条时间线：2027-11-01 启动（肖八 + 核心考点 5 周）→ 2027-12-06 冲刺（肖四选择 + 大题背诵 3 周）。

## 阶段（phase）

阶段是本系统的主结构：**时间 + 目标 + 主线 + 产出 + 检查点 + 进入下一阶段的门槛**。

- 页面只有一条导航轴：**今日计划 / 总体统计 / 阶段总览 / 单科详情**，地址分别是 `#/today`、`#/stats`、`#/phases`、`#/subject/<科目>`，刷新、后退、收藏都落到同一页。
- 「阶段总览」把四科（政治两段，其余三科四段）画在同一张甘特图上：实色 = 进行中、淡色 = 已结束、浅底 = 未开始、黑线 = 今天，点色块直接进该科的阶段详情。
- 甘特图下面四张卡片，每科列出全部阶段的学习日 / 课后题 / 复盘完成度；展开就是阶段目标、主线、产出、检查点、门槛，周骨架再折一层，避免一屏堆几百行。
- 「单科详情」每科一页：今日明细 / 阶段进度 / 章节或单词 / 全部周次 / 打卡日历 / 错题本，页内锚点直接跳；周次默认只展开 12 周，英语 59 周可点「展开全部」。
- 政治 2027-11-01 才启动：启动前在今日计划里显示「还没启动 + 倒计时」，不占计数；单科页显示「还有 N 天开始」。

**细到天的程度不一样**：

- 数学二 / 408：第一阶段的第 1–12 周排到天（寒假之后到阶段收口只锁到周），二三阶段只锁周数。
- 英语：59 周全排到天（单词每天都在滚，重复但必须天天做），2–4 阶段的内容随阶段推进切换。
- 政治：8 周全排到天，2027-11-01 才启动；在启动前打开「今日」会显示「还没启动」和倒计时，不占你的注意力。

阶段数据在四份 JSON 的 `phases` 里，源头是 `scripts/build_phases.py`：`TIMELINE`（三科共用四段）、`POLITICS_TIMELINE`（政治两段），各科 `phases` 里写该段的目标 / 主线 / 产出 / 检查点 / 门槛 / 周骨架。脚本会校验：日期跨度 = 周数 × 7、相邻阶段首尾相接、主线与周骨架的周数合计等于该段周数，然后给周计划打 `phase` 标签。

## 今日计划与单词打卡

**「今日计划」是默认页**：数学二 / 408 / 英语 / 政治当天的任务按科分组排在同一页，每科一块卡片，显示「科目标签 + 当天标题 + 第几周 + 阶段 + 打卡 x/y」。

- 每一项一个勾选框，勾一项就是打卡；顶部圆环是今天的完成率，导航上的「今日计划 x/y」跟着变。
- **勾完不会自动跳天**：最后一勾完成后，那一天会停住并出现「下一天 →」，要手动点才推进（单科页一样）。
- 英语那块把「今日单词」做成带进度的勾选项：勾上就把今天的目标补齐（默认 100 词），再点一次撤销；下面是「复习昨天的生词」和当阶段的任务（阅读 / 题型 / 翻译 / 作文…）。
- 政治没到 11 月时显示「还没启动 · 还有 N 天」，不参与计数。
- 每科右上角「本科详情 →」进**该科的页面**：今天学什么、知识点、动手、课后题都在那里。

### 章节进度（数学二 / 408）

数学二和 408 按**章**推进，教材是武忠祥《高等数学辅导讲义》+ 李永乐《线性代数辅导讲义》和王道四本单科书：

- 「单科详情」的「章节进度」区块：总进度条 + 每本书的分组（高数 0/6、线代 0/6；408 是数据结构 0/8、计组 0/7、OS 0/5、计网 0/6），下面逐章勾选，勾过一章就划线。
- 408 的 26 章默认只展开第一本，点书名列可以收起/展开。
- 勾选后进度条、顶部 KPI、科目胶囊的完成度一起更新，并且可以撤销。
- 「今日计划」里，数学二 / 408 卡片底部也有一行章节进度（总数 + 分组），不用进单科就能看到。
- 正文里的阅读指向也改成讲义：比如「武忠祥讲义 第 2 章（同济 3.1）」，章节按讲义、节号保留同济，方便对照。

### 单词进度（英语）

「单科详情」里英语有一张**今日单词**卡（其他科目没有），下面是近 14 天的背词柱状图。每天的单词任务只有一个入口，不再和计划清单里的「今日新词背完」重复：

| 项 | 说明 |
|---|---|
| 今日目标 | 今日目标 100 词 · 已背 X / 100 的进度条；勾清单里的「今日单词」等于把今天补齐到 100 |
| 轮次 + 进度 | 第 1 轮 · 949 / 6590 · 14.4%，进度条实时更新 |
| 剩余与预计 | 本轮剩 5641 词；按每天 100 词 → 约 57 天，2027-01-03 背完（改每日量会实时重算） |
| 今日范围 | 第 950–1049 词（红宝书第 8 组，按 6590/50 组折算）；背完后仍显示今天的范围，不会跳成明天的 |
| 每日单词量 | −/+ 每次 20，或直接输入，或点 60 / 80 / 100 / 150 快捷值；改了立刻生效并保存 |
| 打卡 / 撤销 | 填「今天实际背了 N 词」（默认填还差的量）→ 打卡；撤销今日把今天记的量退回去，清单勾选也会同步取消 |
| 进度校准 | 直接填「背到第几个词」（比如从 949 改成 1200），用于修正实际进度 |
| 换轮次 | 本轮 6590 背完时出现「开始第 2 轮」，done 归零、轮次 +1 |

单词进度存在浏览器 localStorage 里，跟其他打卡一起导出 / 导入；单科详情顶部的 KPI 也有「单词（第 1 轮）」这一项。

## 交互与视觉

- **科目色**：数学二蓝 / 408 绿 / 英语橙 / 政治红，统一用在科目标签、甘特色块、徽标圆点上。
- **一条导航轴**：顶部只有 4 个页面入口；科目切换放在单科详情页内（科目胶囊），不再和数据页签混在一起。
- **地址即状态**：`#/today`、`#/stats`、`#/phases`、`#/subject/math2`，刷新 / 后退都回到同一页；上次看的页和科目也记在 localStorage 里。
- **改完即时生效**：勾选、章节、单词、排期方式都会写 localStorage 并重绘（保持滚动位置），刷新不丢；重绘只发生在当前页。
- **不自动跳天**：一天全部达标后固定在这一天，显示「下一天 →」手动推进；「全部达标，标记完成」也会把当天的单词补到目标。
- **撤销 Toast**：打卡 / 取消 / 章节 / 单词都弹一条底部提示，4 秒内点「撤销」恢复原状态。
- **打卡日历**：单科详情看本科目的热力图；总体统计看四科合计，颜色越深当天打卡越多，上方是打卡天数 / 当前连续 / 最长连续。完成日会记录日期（`at`），旧记录按计划日回填。
- **总体统计**：四科平均完成度（每科 1/4 权重，避免英语 354 天吃掉比例）、累计学习日、已投入小时、四科对比条（点一行进该科）、最近 7 天、合计日历。

## 怎么用

1. 双击 `22408每日计划.html`（推荐 Chrome / Edge / Safari）。
2. 默认是「今日计划」：四科今天的任务在一页，逐项勾掉就是打卡。
3. 想看四科合起来到哪了，点「总体统计」；想看四科四段路线，点「阶段总览」。
4. 想进某一科：点「单科详情」再点科目胶囊，或在今日计划卡片上点「本科详情 →」。
5. 单科页里：今日明细做课后题、章节进度勾章、英语调每日单词量、全部周次翻周、错题本写错因；做完点「下一天 →」再推进。
6. 换设备或换浏览器：点「导出」，在新设备「导入」（单词进度和每日量一起带走）。

数据只存在当前浏览器的 localStorage，清缓存会丢，重要节点记得导出一次存着。

## 改计划

最省事：改完对应的脚本 / 数据后，一条命令重建全部产物。

```bash
python3 scripts/build.py                # 全部重建（Excel 缺 openpyxl 时自动跳过）
python3 scripts/build.py --only web     # 只重打包网页（改模板 / JSON 后最快）
python3 scripts/build.py --only data    # 只重生成数据（英语 / 政治 / 阶段 / 章节）
```

分步做的话：

```bash
# 0. 改章节表（教材章目录 / 正文里的讲义指向）
python3 scripts/build_chapters.py

# 1. 改阶段（时间、目标、主线、产出、检查点、门槛、周骨架）
#    改 scripts/build_phases.py 里的 TIMELINE / POLITICS_TIMELINE / CS408 / MATH2 / ENGLISH / POLITICS
```
