# 22408 复习计划（2028 考研：数学二 + 408 + 英语 + 政治）

一个纯静态的每日复习计划页 + 一个 Obsidian 笔记库 + 一份 Excel 计划表，三边共用同一套数据。双击 `22408每日计划.html` 就能用，不需要服务器、不需要联网、不需要装任何东西。

四科共用一个「阶段」框架，日期从初试 2027-12-25 倒排：

| 阶段 | 时间 | 周数 | 数学二 | 408 | 英语 | 政治 |
|---|---|---|---:|---|---|---|
| 第一阶段 | 2026-11-09 ~ 2027-03-14 | 18 | 一轮基础 | 一轮基础 | 单词打底 | 不启动 |
| 第二阶段 | 2027-03-15 ~ 2027-06-27 | 15 | 二轮基础 | 二轮基础 | 单词 + 阅读 | 不启动 |
| 第三阶段 | 2027-06-28 ~ 2027-09-26 | 13 | 强化 | 强化 | 阅读 + 题型 | 不启动 |
| 第四阶段 | 2027-09-27 ~ 2027-12-26 | 13 | 真题 | 真题 | 作文 + 真题 | 11 月启动：肖八 → 肖四 |

政治单独一条时间线：2027-11-01 启动（肖八 + 核心考点 5 周）→ 2027-12-06 冲刺（肖四选择 + 大题背诵 3 周）。

## 阶段（phase）

阶段是本系统的主结构：**时间 + 目标 + 主线 + 产出 + 检查点 + 进入下一阶段的门槛**。

- 网页顶部第一排是主入口：**今日计划**（全局）+ 四科（数学二 / 408 / 英语 / 政治），点「今日计划」回到四科合一的打卡页，点某科进该科的「单科今日」。
- 第二排是当前科目的详情页签：单科今日 / 阶段 / 全部周次 / 进度统计 / 错题本。
- 单科页顶部还有四段时间条（政治是两段），当前阶段高亮，点任意一段直接换到那段的内容页。
- 「今日计划」（全局页）顶部显示**四科当前阶段卡**（数学二 / 408 / 英语 / 政治各一张），点哪张就切到那科的「阶段」页；「单科今日」里则是这一科四段的分页切换条。
- 「阶段」页是**分页**的，不是一路往下堆：上面是切换条，中间只显示当前选中的那一段（日期、周数、每周课时、目标、主线、产出、检查点、门槛、周骨架），下面有「← 上一段 / 下一段 →」和「回到当前阶段」。
- 「全部周次」也能按阶段过滤（默认只看当前阶段，避免英语 59 周一路下滑）：已细化的周展开就是每天，其余周显示「待细化」骨架行。
- 「进度统计」多了阶段进度，逐段看完成度。

**细到天的程度不一样**：

- 数学二 / 408：第一阶段的第 1–12 周排到天（寒假之后到阶段收口只锁到周），二三阶段只锁周数。
- 英语：59 周全排到天（单词每天都在滚，重复但必须天天做），2–4 阶段的内容随阶段推进切换。
- 政治：8 周全排到天，2027-11-01 才启动；在启动前打开「今日」会显示「还没启动」和倒计时，不占你的注意力。

阶段数据在四份 JSON 的 `phases` 里，源头是 `scripts/build_phases.py`：`TIMELINE`（三科共用四段）、`POLITICS_TIMELINE`（政治两段），各科 `phases` 里写该段的目标 / 主线 / 产出 / 检查点 / 门槛 / 周骨架。脚本会校验：日期跨度 = 周数 × 7、相邻阶段首尾相接、主线与周骨架的周数合计等于该段周数，然后给周计划打 `phase` 标签。

## 今日计划与单词打卡

**「今日计划」是全局页（默认打开）**：数学二 / 408 / 英语 / 政治四科当天的任务按科目分组排在同一页，每科一块卡片，显示「科目标签 + 当天标题 + 第几周 + 阶段 + 打卡 x/y」。

- 每一项一个勾选框，勾一项就是打卡；页面顶部有 4 科合计的「x / y 项」总进度条。
- 英语那块多一行单词进度：`单词 949/6590（第 1 轮）` + 进度条 + 今日范围 + 「+100 词」快捷打卡。
- 政治没到 11 月时显示「还没启动 · 还有 N 天」，不参与计数。
- 每科右上角「细节 →」（或点顶部科目名）进**「单科今日」**：今天学什么、知识点、动手、课后题都在那里。

### 章节进度（数学二 / 408）

数学二和 408 按**章**推进，教材是武忠祥《高等数学辅导讲义》+ 李永乐《线性代数辅导讲义》和王道四本单科书：

- 单科今日页右侧有「章节进度」卡：总进度条 + 每本书的分组（高数 0/6、线代 0/6；408 是数据结构 0/8、计组 0/7、OS 0/5、计网 0/6），下面逐章勾选，勾过一章就划线。
- 408 的 26 章默认只展开第一本，点书名列可以收起/展开。
- 「进度统计」页有同一份章节表（两列布局），可以一次看全。
- 全局「今日计划」里，数学二 / 408 卡片底部有一行章节进度（总数 + 分组），不用进单科也能看到。
- 正文里的阅读指向也改成讲义：比如「武忠祥讲义 第 2 章（同济 3.1）」，章节按讲义、节号保留同济，方便对照。

### 单词进度（英语）

「单科今日」里英语有一张**单词进度**卡，其他科目没有：

| 项 | 说明 |
|---|---|
| 轮次 + 进度 | 第 1 轮 · 949 / 6590 · 14.4%，进度条实时更新 |
| 剩余与预计 | 本轮剩 5641 词；按每天 100 词 → 约 57 天，2027-01-03 背完（改每日量会实时重算） |
| 今日范围 | 第 950–1049 词（红宝书第 8 组，按 6590/50 组折算） |
| 每日单词量 | −/+ 每次 20，或直接输入，或点 60 / 80 / 100 / 150 快捷值；改了立刻生效并保存 |
| 打卡 / 撤销 | 填「今日背了 N 词」→ 打卡（可只记一部分）；撤销今日会把今天记的量退回去 |
| 进度校准 | 直接填「背到第几个词」（比如从 949 改成 1200），用于修正实际进度 |
| 换轮次 | 本轮 6590 背完时出现「开始第 2 轮」，done 归零、轮次 +1 |

单词进度存在浏览器 localStorage 里，跟其他打卡一起导出 / 导入；单科顶部进度卡也有「单词（第 1 轮）」这一项。

## 交互与视觉

- **科目色**：数学二蓝 / 408 绿 / 英语橙 / 政治红，统一用在顶部科目标签、阶段条高亮、徽标圆点上，切科一眼能看出来。
- **局部更新**：勾今日计划、勾章节只更新那一行和计数，不再整页重绘，滚动位置和焦点不会跳。
- **撤销 Toast**：打卡 / 取消 / 章节 / 单词都弹一条底部提示，4 秒内点「撤销」恢复原状态。
- **打卡日历**：进度统计页画热力图（一行一天，颜色越深当天打卡越多），上方显示「打卡天数 / 当前连续 / 最长连续」。完成日会记录日期（`at`），旧记录按计划日回填。
- **全局统计**：进度统计默认是「全局」，给出四科平均完成度（每科 1/4 权重）、累计完成学习日、已投入小时、四科对比条与对比卡（学习日 / 章节或单词 / 近 7 天打卡），底部是**四科合计**的打卡日历；点某科卡片可以下钻到单科统计。

## 怎么用

1. 双击 `22408每日计划.html`（推荐 Chrome / Edge / Safari）。
2. 顶部四个科目：数学二 / 408 / 英语 / 政治，各自独立记进度。
3. 科目下面那条时间条显示现在在第几段、还剩多少天；点它跳到「阶段」页。
4. 打开就是「今日计划」：四科今天的任务在一页，逐项勾掉就是打卡；顶部看合计进度。
5. 要看今天学什么 / 做课后题 / 调单词量，点那一科的「细节 →」进「单科今日」。
6. 不会的题先「记入错题本」，之后在错题本里写错因、标已掌握。
7. 换设备或换浏览器：点「导出」，在新设备「导入」（单词进度和每日量一起带走）。

数据只存在当前浏览器的 localStorage，清缓存会丢，重要节点记得导出一次存着。

## 改计划

最省事：改完对应的脚本 / 数据后，一条命令重建全部产物。

```bash
python3 scripts/build.py                # 全部重建（Excel 缺 openpyxl 时自动跳过）
python3 scripts/build.py --only web     # 只重打包网页（改模板 / JSON 后最快）
python3 scripts/build.py --only data    # 只重生成数据（英语 / 政治 / 阶段 / 章节）
```

分步做的话：

```bash
# 0. 改章节表（教材章目录 / 正文里的讲义指向）
python3 scripts/build_chapters.py

# 1. 改阶段（时间、目标、主线、产出、检查点、门槛、周骨架）
#    改 scripts/build_phases.py 里的 TIMELINE / POLITICS_TIMELINE / CS408 / MATH2 / ENGLISH / POLITICS
python3 scripts/build_phases.py     # 写回四份 JSON，顺带校验周数是否对得上

# 2. 改英语 / 政治的每日内容
#    英语词库总数 / 起点 / 默认每日量 → 改 scripts/gen_english_plan.py 里的 wordBook
python3 scripts/gen_english_plan.py
python3 scripts/gen_politics_plan.py
python3 scripts/build_phases.py     # 再注入阶段（会覆盖生成器里的 title）

# 3. 改 12 周的逐日排期（周次地图，很少动；读的是 22 周原版 JSON，见 scripts/_archive/）
python3 scripts/_archive/rebuild_app_plan.py
python3 scripts/build_chapters.py   # 重排会覆盖章节表，重跑补回

# 4. 打包网页（自动同步 deploy/index.html）
python3 scripts/build_v2.py

# 5. 重建 Excel（需要 openpyxl）
python3 scripts/build_plan_v2.py

# 6. 重建 Obsidian 笔记库
python3 scripts/build_obsidian_vault.py
```

只改界面样式的话，改 `web/plan-app-v2.template.html` 后跑 `python3 scripts/build_v2.py`。
